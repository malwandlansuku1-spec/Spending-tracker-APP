# Spending-tracker-APP
OBJECTIVE 
The cost of living has increased dramatically in 2026 .Apps help monitor daily spending. It is important to you to track your spending and align it with daily budget to see whether you are saving money .

features 
4 parallel arrays 7 elements each: 
array 1:date 
Array 2:daily budget 
array 3:dailyspent 
Array 4:comments 

SCREEN NAVIGATION 
Main activity > Detailed activity using intent
data calculations:total,average,days over budget highest\lowest ,savings using loops

TECH
kotlin, Github ,Github Actions 

ARRAYS 
array 1:date (2026-10-07 - 2026-10-13)
Array 2:daily budget (500,250,300,400,320,210,470)
array 3:dailyspent (340,250,300,400,320,210,470)
Array 4:comments (grocery shopping ,takeaways, petrol, maintanance, clothes, online shopping, thrifting )

GITHUB ACTION
Automated using IMAD
